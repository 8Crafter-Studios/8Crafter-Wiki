## What Are Configs?

A config allows you to configure the Ore UI Customizer.

The way configs work is by operating on the Ore UI files, like the Ore UI Customizer does.

Configs come in a `.ouicconfig`, `.mcouicconfig`, or `.json` <!-- `.jsonc`, `.json5`, `.jsonl`, `.jsonld` --> file.

Configs can change Ore UI Customizer settings, including color customizations for Ore UI.
