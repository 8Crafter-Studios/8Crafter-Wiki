This is a web application that allows you upload .mcstructure files and convert them into a behavior pack that you can add to your Minecraft Bedrock Edition world/realm/server, and it will allow you to import them in-game with a [structure block](https://minecraft.wiki/w/Structure_Block) or the [`/structure`{lang=mccmd}](https://minecraft.wiki/w/commands/structure) command.

Even though this web application is part of my website, you can also use it offline if you are able to use Node.js by just running my website on your device with Node.js. You just clone the repository to your device and run the index.js file. Then you can navigate to the page as normal.
