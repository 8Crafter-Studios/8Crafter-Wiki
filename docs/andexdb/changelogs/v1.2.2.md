A change in the UUID of the behavior pack was required to fix the issues so any data stored in the dynamic properties of the add-on on versions 1.2.1 and below WILL NOT BE TRANSFERRED to versions 1.2.2 and above so make sure that you write down any variable that you want to transfer so that you can manually set them again.
