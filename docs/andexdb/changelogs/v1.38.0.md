**Updated the add-on to 1.21.90!**

## Additions

-   Added the `playerPermissionLevel` and `commandPermissionLevel` properties to the info logged by the [player debug stick](../items/player-debug-stick).

## Removals

-   Removed the `Set Operator` option from the [player controller](../items/player-controller) as the API methods for it were removed in 1.21.90.
-   Removed the [`isOp`{lang=ts}](https://docs.api.8crafter.com/andexdb/v1.37.1/classes/Globals.modules.playersave.savedPlayer.html#isop) property from the offline player information as the API methods for it were removed in 1.21.90 (the property will still exist for players who last joined on a previous version).
-   Removed the `isOp` property from the info logged by the [player debug stick](../items/player-debug-stick) as the API methods for it were removed in 1.21.90.

## Fixes

-   The `Requires Operator` option for the add-on's commands is now accurate on realms and servers, this wasn't possible before but was made possible in 1.21.90.
