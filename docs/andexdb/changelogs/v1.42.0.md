**Updated the add-on to 1.26.0!**

## Breaking Removals

-   Removed the `@minecraft/server-admin` module from the pack's `manifest.json` file, meaning to use it you will have to manually uncomment it in the `manifest.json` file of the behavior pack. This was done to keep the pack compatible with Realms, as Microsoft removed the ability to use the `@minecraft/server-admin` module on Realms 😭.
    -   As a result of this, the transfer players feature is no longer functional unless the module is manually uncommented in the `manifest.json` file of the behavior pack, this also means the transfer players feature cannot be used on Realms ever again, as the module no longer works on Realms due to Microsoft removing really good features 😭.

## Changes

### Items

-   The [Debug Screen](../items/debug-screen) is no longer available in the creative inventory as it serves no practical use as it was never actually developed and is just a crude version of the [Editor Stick](../items/editor-stick) (it can still be obtained through commands).

### UIs

-   The "8Crafter's Server Utilities & Debug Sticks" button on the vanilla settings menu has been renamed to "8Crafter's Server Utilities".

## Fixes

### UIs

-   Fixed a bug where the title of the "Parameters Basics" section of the "8Crafter's Server Utilities" section of the "How to Play" screen had a title of `andexdb.commandsParametersBasics.title` instead of `Commands Parameters Basics`.

## Technical Additions

### API

-   The following modules will now be automatically imported into the [`modules`{lang=ts}](https://api.8crafter.com/andexdb/v1.42.0/modules/Globals.modules.html) namespace if they are added into the `manifest.json`:
    -   `@minecraft/server-graphics`
-   The following modules will now be automatically imported into the [`modules`{lang=ts}](https://api.8crafter.com/andexdb/v1.42.0/modules/Globals.modules.html) namespace if they are available:
    -   `@minecraft/server-bindings`
    -   `@minecraft/server-private-bindings`
    -   `@minecraft/server-ui-bindings`
    -   `@minecraft/server-ui-private-bindings`

## Technical Changes

### API

-   Updated the [`@minecraft/vanilla-data`](https://api.8crafter.com/andexdb/v1.42.0/modules/_minecraft_vanilla-data.html) module from `v1.21.120` to `v1.26.0`.
