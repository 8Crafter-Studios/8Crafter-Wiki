## Changes

### Items

-   The [Debug Screen](../items/debug-screen) is no longer available in the creative inventory as it serves no practical use as it was never actually developed and it just a crude version of the [Editor Stick](../items/editor-stick) (it can still be obtained through commands).

### UIs

-   The "8Crafter's Server Utilities & Debug Sticks" button on the vanilla settings menu has been renamed to "8Crafter's Server Utilities".

## Fixes

### UIs

-   Fixed a bug where the title of the "Parameters Basics" section of the "8Crafter's Server Utilities" section of the "How to Play" screen had a title of `andexdb.commandsParametersBasics.title` instead of `Commands Parameters Basics`.
