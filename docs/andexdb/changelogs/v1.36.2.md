## Critical Bug Fixes

-   Fixed a bug where the files in the UI folder related to the `ModalFormData`{lang=ts} and `ActionFormData`{lang=ts} were not updated, causing labels, headers, and dividers, in button forms and input forms to break the entire UI (this bug has existed since `v1.33.0`).
-   Fixed a bug where the file in the UI folder for the custom settings section for the add-on that shows info about it was not updated to use the add-on's new name: "8Crafter's Server Utilities".
