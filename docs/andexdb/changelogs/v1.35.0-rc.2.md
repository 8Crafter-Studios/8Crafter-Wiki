## Changes

### UIs

-   Added a delete button to the submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to manage a specific event subscription.
-   Added a move button to the submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to manage a specific event subscription, this allows for changing the execution order of event subscriptions, event subscriptions at the top of the list (lower index) will be executed first.
-   Added a refresh button to the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu.
-   Added a statistics button to the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu.
-   The submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to manage a specific event subscription now displays the event subscription's execution order.
-   The edit code button for the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu now automatically reinitializes the event subscription when the code is edited.
-   When enabling or disabling an event subscription in the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu, the event subscription will be automatically initialized or deinitialized, respectively, so that it is enabled or disabled immediately, instead of only once the event subscriptions are reloaded.
-   The [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu now shows the total number of event subscriptions in each category.
-   The submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to choose between the before and after events now shows the total number of event subscriptions in each category.
-   The refresh button for the submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to choose between the before and after events now refreshes the displayed number of event subscriptions in each category instead of throwing an error.
-   The submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to manage the event subscriptions on a specific event now automatically refreshes after creating an event subscription (only for the person who created the event subscription).
-   The submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to manage the event subscriptions on a specific event is no longer sorted, so as to make the event subscriptions be ordered by their execution order.

## Fixes

### Commands

-   Fixed a bug where the `scale`, `scalex`, `scaley`, and `scalez` subcommands for the [`\\expandselection`{lang=acmd}](../commands-list/--expandselection) command just scaled the pos1 position by the specified amount instead of scaling the distance between the pos1 and pos2 positions from the center of the selection.

### Items

#### Editor Stick

-   Fixed a bug where the 3 editor stick types would set the sign text color on the opposite side of what was specified. (ANDEXDB-63)

### Settings

-   Fixed a bug where the [Main Menu Settings](../settings/ui/menu-configurations/main-menu/main-menu-settings) menu was accessing the player menu config ([`config.ui.menus.playerMenu`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.ui.menus.playerMenu.html)) instead of the main menu config ([`config.ui.menus.mainMenu`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.ui.menus.mainMenu.html)).

### UIs

-   Fixed a bug where the submenu of the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu to edit the event subscriptions on a specific event used the grid menu form style instead of the medium form style.

## Technical Fixes

### Permanent Event Subscriptions

-   Fixed a bug where subscriptions to the [`andexdb.afterEvents.modifiedChatMessageSend`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbAfterEvents.html#modifiedchatmessagesend) event were actually subscribed to its [`before event`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbBeforeEvents.html#modifiedchatmessagesend) variant instead.
-   Fixed a bug where the [`SubscribedEvent.prototype.creationTime`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.SubscribedEvent.html#creationtime) getter returned `NaN`{lang=ts}, causing all the places where an event subscription's creation time was displayed to show `NaN`{lang=ts}.
