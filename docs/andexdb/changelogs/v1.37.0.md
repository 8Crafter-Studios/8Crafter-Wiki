### Commands

-   Reworked the maze generator in the [`\\maze`{lang=acmd}](../commands-list/--maze) command to be a lot more CPU and memory efficient.
-   The undo system now has multiple separate undo clipboards so that each player can have their own separate undo history, the player can also specify an undo clipboard to undo from in the [`\\undo`{lang=acmd}](../commands-list/--undo) command.
-   Added the `g` flag to the [`\\undo`{lang=acmd}](../commands-list/--undo) command to undo the last action from any undo clipboard.
-   Changed the syntax of the [`\\undo`{lang=acmd}](../commands-list/--undo) command from `\\undo [-kt]`{lang=acmd} to `\\undo [-ktg] {[undoClipboard: string[?=PersonalClipboardID]]}`{lang=acmd}.
-   Changed the syntax of the [`\\cut`{lang=acmd}](../commands-list/--cut) command from `\\cut [-meb]`{lang=acmd} to `\\cut [-meb] {[clipboard: (string|{global})[?=PersonalClipboardID]]}`{lang=acmd}.
-   Changed the syntax of the [`\\copy`{lang=acmd}](../commands-list/--copy) command from `\\copy [-meb]`{lang=acmd} to `\\copy [-meb] {[clipboard: (string|{global})[?=PersonalClipboardID]]}`{lang=acmd}.
-   Changed the syntax of the [`\\paste`{lang=acmd}](../commands-list/--paste) command from `\\paste [-webxzh] [integrity: float] [integritySeed: string] [rotation: 0|90|180|270] [animationMode: none|blocks|layers] [animationSeconds: float]`{lang=acmd} to `\\paste [-webxzh] {[clipboard: (string|{global})[?=PersonalClipboardID]]} [integrity: float[?=1]] [integritySeed: string] [rotation: (0|90|180|270)[?=0]] [animationMode: {none}|{blocks}|{layers}] [animationSeconds: float[?=0]]`{lang=acmd}.
-   The [`\\paste`{lang=acmd}](../commands-list/--paste) and [`\\undo`{lang=acmd}](../commands-list/--undo) commands now paste/undo asynchronously to avoid script hang errors when pasting/undoing large areas.
-   Changed the syntax of the [`\\brush`{lang=acmd}](../commands-list/--brush) command from

```acmd
\brush [-l] none
\brush [-l] <brushType: sphere|cube|square>` /*+` [-h]`*/ + ` <blockPattern: BlockPattern> [radius: float] [mask: Mask]
\brush [-l] <brushType: splatter|splattercube|splattersquare|splattersurface|splattercubesurface|splattersquaresurface> [-h] <blockPattern: BlockPattern> [radius: float] [decay: float] [mask: Mask]
\brush [-l] <brushType: extinguish|ex|remexp> [radius: float]
```

to

```acmd
\brush [-l] none
\brush [-l] <brushType: sphere|cube|square> <blockPattern: BlockPattern> [radius: float[?=3]] [mask: Mask]
\brush [-l] <brushType: splatter|splattercube|splattersquare|splattersurface|splattercubesurface|splattersquaresurface|overlaysurface|overlaycubesurface|overlaysquaresurface> [-h] <blockPattern: BlockPattern> [radius: float[?=3]] [decay: float[?=0]] [mask: Mask]
\brush [-l] <brushType: flattenfill|flattensquarefill> [-r] <flattenDirection: {up}|{down}|{north}|{south}|{east}|{west}|{auto}|{autor}> <blockPattern: BlockPattern> [radius: float[?=3]] [decay: float[?=0]] [mask: Mask]
\brush [-l] <brushType: flatten|flattensquare> [-rw] <flattenDirection: {up}|{down}|{north}|{south}|{east}|{west}|{auto}|{autor}> [radius: float[?=3]] [decay: float[?=0]] [mask: Mask]
\brush [-l] <brushType: nudge|nudgecube> [-t] <nudgeDirection: {up}|{down}|{north}|{south}|{east}|{west}|{auto}|{autor}> [radius: float[?=3]] [decay: float[?=0]] [mask: Mask]
\brush [-l] <brushType: copy|copycube> [-a] {[clipboard: (string|{global})[?=PersonalWorldEditBrushClipboardID]]} [radius: float[?=3]] [decay: float[?=0]] [mask: Mask]
\brush [-l] <brushType: paste> {[clipboard: (string|{global})[?=PersonalWorldEditBrushClipboardID]]}
\brush [-l] <brushType: ex|extinguish|remexp|remexpe|remexpne> [radius: float[?=10]]
```

-   The block clipboard system now has multiple separate block clipboards so each player can have their own clipboards to copy stuff to, players can also specify a specific clipboard ID to use in the WorldEdit commands that deal with the block clipboard ([`\\cut`{lang=acmd}](../commands-list/--cut), [`\\copy`{lang=acmd}](../commands-list/--copy), [`\\paste`{lang=acmd}](../commands-list/--paste), [`\brush`{lang=acmd}](../commands-list/-brush), etc.).

### Performance

-   Massive performance improvements to the [Money System](../systems/money).

### UIs

-   Added a button to access the texture preset selector to the manage warp menu.
-   Added a note to the create warp menu that you can put `~~~`{lang=mccmd} into the location text box to use your current location as the warp's location.

## Fixes

### Block Masks

-   Fixed a bug where block masks did not test for block tags when testing on a `Block`{lang=ts} instance.

### Commands

-   Reworked the maze generator in the [`\\maze`{lang=mccmd}](../commands-list/--maze) command to generate the mazes correctly instead of having two block dead-ends to the left and right every two blocks.

### Player Data Auto Save

-   Fixed a bug where a bunch of errors about a location being in an unloaded chunk would be thrown when a player was changing dimensions.

## Technical Additions

### API

-   Added the [`modules.utils.dirreversemap`{lang=ts}](https://api.8crafter.com/andexdb/v1.37.0-preview.20/functions/Globals.modules.utils.dirreversemap.html) function.

## Technical Changes

### API

-   The [`modules.utils.getDetailedType`](https://api.8crafter.com/andexdb/v1.37.0-preview.20/functions/Globals.modules.utils.getDetailedType.html) function now has special handling for functions, symbols, `Infinity`{lang=ts}, `-Infinity`{lang=ts}, and `NaN`{lang=ts} values.
-   Complete overhaul of [`modules.coords.BlockClipboard`{lang=ts}](https://api.8crafter.com/andexdb/v1.37.0-preview.20/classes/Globals.modules.coords.BlockClipboard.html).
-   Complete overhaul of [`modules.coords.UndoClipboard`{lang=ts}](https://api.8crafter.com/andexdb/v1.37.0-preview.20/classes/Globals.modules.coords.UndoClipboard.html).
-   The [`config.toJSON`{lang=ts}]() method new accepts a subconfig as an optional parameter, so that to convert a subconfig to JSON, you can pass it directly instead of using `config.toJSON.apply`.
