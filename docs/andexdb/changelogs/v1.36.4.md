## Fixes

### Commands

-   Fixed the [`\terminal`{lang=acmd}](../commands-list/-terminal) command.
-   Fixed the [`\messageui`{lang=acmd}](../commands-list/-messageui) command.
-   Fixed the [`\chatsendui`{lang=acmd}](../commands-list/-chatsendui) command.
-   Fixed the [`\chatcommandui`{lang=acmd}](../commands-list/-chatcommandui) command.

### Custom Protected Area Categories

-   Fixed a bug where when creating a new protected area in a custom area category through the UI, the new protected area would not be saved properly.
-   Fixed a bug where when creating a new custom protected area category through the UI, the new custom area category did not have its area list initialized, causing it to be unable to have areas added to it until the category was reloaded.
-   Fixed a bug where when editing a custom protected area category, all buttons after the "Explosion Prevention" button did what the button before them was supposed to do, including the back and close buttons.
