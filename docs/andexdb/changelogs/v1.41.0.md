**Updated the add-on to 1.21.120!**

## Changes

-   The `loot_tables/maps/andexdb/randommap`{lang=mccmd} loot table now only gives map types that are actually supported by the game.
-   The `loot_tables/maps/andexdb/endcity`{lang=mccmd} now has a default name of `§r§fEnd City Explorer Map` instead of just being called `Map 0`.
-   The following loot tables no longer have custom names and instead use their vanilla names:
    -   `loot_tables/maps/andexdb/jungle_template`{lang=mccmd}
    -   `loot_tables/maps/andexdb/swamp_hut`{lang=mccmd}
    -   `loot_tables/maps/andexdb/trial_chambers`{lang=mccmd}
    -   `loot_tables/maps/andexdb/village_desert`{lang=mccmd}
    -   `loot_tables/maps/andexdb/village_plains`{lang=mccmd}
    -   `loot_tables/maps/andexdb/village_savanna`{lang=mccmd}
    -   `loot_tables/maps/andexdb/village_snowy`{lang=mccmd}
    -   `loot_tables/maps/andexdb/village_taiga`{lang=mccmd}
-   Updated the recipes for the [Enchantment Transfer Smithing Template](../items/enchantment-transfer-smithing-template) (this should fix a few content log errors and allow enchanting newer items).

## Fixes

-   Fixed a content log error relating to there being a comment in an `.mcfunction` file which was not allowed.
-   Fixed a bug where the Manage Server Shops menu had incorrect button mappings, resulting in different buttons than the one you clicked being pressed or errors.

## Technical Additions

### API

-   The following modules will now be automatically imported into the [`modules`{lang=ts}](https://api.8crafter.com/andexdb/v1.41.0/functions/Globals.modules.html) namespace if they are added into the `manifest.json`:
    -   `@minecraft/server-net`
    -   `@minecraft/server-editor`
        -   The following modules will also be imported if `@minecraft/server-editor` is added to the `manifest.json`:
            -   `@minecraft/server-editor-bindings`
            -   `@minecraft/server-editor-private-bindings`
    -   `@minecraft/debug-utilities`
    -   `@minecraft/diagnostics`

### Debugging

-   The startup time console log now also includes the total startup time (pre-startup time + startup time), pre-startup time, and exiting early-execution delay, instead of just the startup time.

## Technical Changes

-   Updated the [`@minecraft/vanilla-data`](https://api.8crafter.com/andexdb/v1.41.0/modules/_minecraft_vanilla-data.html) module from `v1.21.110` to `v1.21.120`.

## Technical Fixes

### API

-   Fixed a bug where the [`twoWayModulo`{lang=ts}](https://api.8crafter.com/andexdb/v1.41.0/functions/Globals.twoWayModulo.html) function would return the modulus instead of 0 when the number was negative and a multiple of the modulus.
