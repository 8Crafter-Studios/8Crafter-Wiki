**Renamed the add-on from `8Crafter's Debug Sticks, Chat Ranks, Custom UI, JavaScript Commands/Script REPL, and Server Utilities` to `8Crafter's Server Utilities & Debug Sticks`!**

## Additions

### Blocks

-   Added the [`andexdb:invalid_block_placeholder`{lang=mccmd}](../blocks/invalid-block-placeholder#Normal) block.
-   Added the [`andexdb:invalid_block_placeholder_no_occlusion_no_dimming`{lang=mccmd}](../blocks/invalid-block-placeholder#No_Occlusion%2C_No_Dimming) block.
-   Added the [`andexdb:invalid_block_placeholder_lit`{lang=mccmd}](../blocks/invalid-block-placeholder#Lit) block.

### Chat Escape Codes

-   Added the `${ase}` chat secape code, which is the same as `${se}` except that is evaluates the provided script in an asynchronous function, so `system.run()`{lang=ts} is not needed to use functions that can't be used in read-only mode, and you can use the `await` keyword. And awaited promises will actually have their errors caught and logged to the chat, instead of only to the console, which you wouldn't be able to see the errors from unless you were on a dedicated server and had console access, or were on a world and you were the host. It requires the same permissions as the `${se}` escape code.

### Commands

-   Added the [`\\loadchunks`{lang=acmd}](../commands-list/--loadchunks) command. It has one alias: `\\lc`{lang=acmd}.
-   Added the `duration` parameter to the [`\selectionrender`{lang=acmd}](../commands-list/-selectionrender) command.
-   Added the `t` flag to the [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command. This flag causes the command to create ghost items if the slot type is a number or `~`.
-   Added the [`\tpaccept`{lang=acmd}](../commands-list/-tpaccept) command.
-   Added the [`\tpdeny`{lang=acmd}](../commands-list/-tpdeny) command.
-   Added the [`\gmg`{lang=acmd}](../commands-list/-gmg) command.
-   Added the [`\\expandselection`{lang=acmd}](../commands-list/--expandselection) command.
-   Added the [`\\generateterrain`{lang=acmd}](../commands-list/--generateterrain) command.
-   Added the `f` flag to the [`\\remove`{lang=acmd}](../commands-list/--remove) command. This flag causes the command to execute in fast mode, fast mode causes the command to run all in one tick and using [`BlockVolumeBase.prototype.getBlockLocationIterator()`{lang=ts}](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/blockvolumebase?view=minecraft-bedrock-experimental#getblocklocationiterator) to get all the non-air blocks in the selected area. Note: This flag will cause the command to freeze the world/realm/server until it finishes executing or triggers a script hang error.

### Mute System

Added a new [Mute System](../systems/mute)!

You can mute players through the [Quick Mute](../main-menu/moderation#quick-mute) menu.

You can also mute or unmute players through the [Manage Players](../main-menu/manage-players) menu.

You can also manage mutes through the [Manage Mutes](../main-menu/moderation#manage-mutes) menu.

### Settings

-   Added the [`Default Min MS Between Tick Waits`](../settings/script#default-min-ms-between-tick-waits) setting ([`config.system.defaultMinMsBetweenTickWaits`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.system.html#defaultminmsbetweentickwaits)) to the [Script Settings](../settings/script) menu.
-   Added 4 new options related to the console and chat logs about whether or not a compatible version of the [BlueMods Anticheat](/../main/add-ons/bluemods-anticheat) add-on is on the world to the [Script Settings](../settings/script) menu.

### UIs

-   Huge overhaul to the [Moderation](../main-menu/moderation) menu.
    -   The menu now disabled the non-functional buttons.
    -   Rearranged the buttons on the menu.
    -   Added the [Quick Actions](../main-menu/moderation#quick-actions) submenu.
        -   This submenu contains buttons for quickly banning, kicking, and muting players, and even transferring players to other servers!
    -   Huge internal structure overhaul to improve performance and make it easier to add new features.
-   Added menus for resetting player and preset permissions in Ultra Security Mode.

### Ultra Security Mode

#### Permissions

-   Added the `andexdb.bypassTeleportCooldowns` permission to Ultra Security Mode.
-   Added the `andexdb.transferPlayers` permission to Ultra Security Mode.
-   Added the `andexdb.mutePlayers` permission to Ultra Security Mode.
-   Added the `andexdb.unmutePlayers` permission to Ultra Security Mode.
-   Added the `andexdb.accessManageMutesUI` permission to Ultra Security Mode.
-   Added the `andexdb.useScriptEval` permission to Ultra Security Mode.

## Changes

### Commands

-   The [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command now no longer creates ghost items, unless the new `t` flag is used and the slot type is a number or `~`.
-   The [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command now takes a target selector instead of a player name.
-   The [`\copyitem`{lang=acmd}](../commands-list/-copyitem) command now takes a target selector instead of a player name.
-   The [`\copyitem`{lang=acmd}](../commands-list/-copyitem) command now allows for multiple targets.
-   The [`\tpa`{lang=acmd}](../commands-list/-tpa) command now uses the new [TPA system](../systems/tpa).
-   The [`\gmr`{lang=acmd}](../commands-list/-gmr) command now has a chance to set you to god mode (Game Mode 7).
-   The [`\help`{lang=acmd}](../commands-list/-help) command now displays the URL of the page on the wiki for the command when getting the help for a built-in command.

### Performance

-   Massive performance improvements to the [Money System](../systems/money).

### Settings

-   Massive overhaul to the [Script Settings](../settings/script) menu.
-   The [Module Imports Config](../settings/module-imports) now defaults to having everything enabled.

### Teleport Systems

-   Made it so if Ultra Security Mode is enabled, players with the `andexdb.bypassTeleportCooldowns` permission can bypass the countdown and cooldown for teleports with things such as the homes and warps systems, and if Ultra Security Mode is disabled, then players with the `admin` tag can bypass it.

### TPA System

-   The [TPA system](../systems/tpa) is no longer experimental.

### UIs

-   Made the "Reset Permissions" button in the Security menu use the red reset icon instead of the settings icon.
-   Made the "Ultra Security Mode Debug" button in the security settings menu use the debug glyph color icon instead of the settings icon.
-   The [Eval Auto Execute Settings](../settings/advanced/eval-auto-execute) menu now requires the `andexdb.useScriptEval` and `andexdb.accessAdvancedSettings` permissions when Ultra Security Mode is enabled (before it only needed `andexdb.accessSettings`).
-   Depecated the [Eval Auto Execute Settings](../settings/advanced/eval-auto-execute) menu.
-   Added a Done button to the View Raw Data menu of the Edit Custom Area Category menu to allow players using controllers to scroll in the menu.

## Removals

### Permanent Event Subscriptions

-   Added a new permanent event subscriptions system.
    -   The new permanent event subscriptions system allows you to register code that will execute when an event occurs.
    -   It supports ALL vanilla script API events, and a few custom events.
    -   It supports the following custom events:
        -   [`andexdb.beforeEvents.modifiedChatMessageFormat`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbBeforeEvents.html#modifiedchatmessageformat)
        -   [`andexdb.beforeEvents.modifiedChatMessageFormatFinalization`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbBeforeEvents.html#modifiedchatmessageformatfinalization)
        -   [`andexdb.beforeEvents.modifiedChatMessageSend`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbBeforeEvents.html#modifiedchatmessagesend)
        -   [`andexdb.afterEvents.modifiedChatMessageSend`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/_internal_.andexdbBeforeEvents.html#modifiedchatmessagesend)
    -   You can create these permanent event subscriptions either through the [script eval](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.Events.html) or the [Manage Event Subscriptions](../settings/advanced/manage-event-subscriptions) menu.
