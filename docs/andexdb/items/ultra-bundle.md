The ultra bundle is the same as the normal bundle, but it can holder shulker boxes in it, which allows for shulker nesting, it also can be dyed any color with a cauldron.

To shulker nest using the ultra bundle, place the shulker box inside the ultra bundle, and then place the ultra bundle inside another shulker box.
