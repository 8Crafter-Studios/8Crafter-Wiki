<Spoiler title="What custom launchers can this app have built-in world paths for?">

The custom launchers that this app can see worlds from without you needing to add the paths to the config manually include:

-   Bedrock Launcher (Windows) (it can show worlds from all of your installations if you click the "Show more" button, otherwise it just shows the active installations)
-   LeviLauncher (Windows) (support for showing worlds from all installations will be added in a future update, for now it only shows the active installations)
-   Minecraft Bedrock Launcher/mcpelauncher (Linux/macOS)
-   PlayCover (macOS)
-   Any Windows launcher that symlinks the worlds into the vanilla UWP or GDK `minecraftWorlds` folder.

If you know of another launcher please tell 8Crafter about it via [email](mailto:8crafteryt@gmail.com) or the [8Crafter Studios](https://discord.8crafter.com) discord server, please include the path to the folder that contains the `minecraftWorlds` or `worlds` folder.

</Spoiler>
